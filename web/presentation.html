FÍSICA Y SOFTWARE

Un núcleo. Tres formas de usarlo.

Las interfaces presentan los datos; el modelo, los integradores y el análisis viven en Python.

Web

Python y NumPy mediante Pyodide. Sin servidor de cálculo; los intentos se conservan en memoria durante la sesión.

Entrar al laboratorio →

Escritorio

Interfaz PySide6 para recorrer casos guiados, comparar intentos y explorar el modelo en modo libre.

uv run --extra desktop python -m sincrolab.interfaces.desktop

CLI y API

Ejecuciones reproducibles y exportación estructurada de resultados. El mismo contrato de aplicación, sin dependencia de la GUI.

uv run sincrolab reference run stable_transient

Lo que representa el modelo

Una máquina síncrona y una barra infinita, con etapas prefalla, falla y posfalla mediante cambios de potencia máxima equivalente. El diagnóstico se limita a la primera oscilación muestreada. No es un cálculo completo de cortocircuito ni un estudio operacional de una red real.

EVIDENCIA INSPECCIONABLE

El rigor también se puede revisar.

Hipótesis, unidades y tolerancias explícitas para distinguir el resultado del modelo de su interpretación.

  • Pruebas analíticas de los integradores y estudio de convergencia.
  • Comparación independiente con SciPy en el entorno de pruebas.
  • Casos sintéticos reproducibles y sensibilidad al paso temporal.
  • Eventos en su instante especificado y procedencia de cada trayectoria.
  • Criterio de áreas iguales en casos compatibles y búsqueda temporal con extremos evaluados.
